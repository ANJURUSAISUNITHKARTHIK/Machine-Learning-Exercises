# Titanic Survival Prediction

## Objective
Predict whether passengers survived using machine learning models.

## Algorithms Used
- Logistic Regression
- Random Forest

## Steps Performed
- Data Loading
- Data Cleaning
- Missing Value Handling
- Feature Engineering
- Model Training
- Model Evaluation

## Results
- Logistic Regression Accuracy: 80%
- Random Forest Accuracy: 82%

## Dataset
Titanic Dataset from Kaggle
